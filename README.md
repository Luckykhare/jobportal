# Job Portal

A full-featured Job Portal web application that allows job seekers to find and apply for jobs, and employers to post and manage job listings.


# clone the repository
   git clone https://github.com/Luckykhare/jobportal
   create frontend folder
   create backend folder

 # MOove into the project folder
   cd frontend

# install dependencies
  npm install

#  start the development server
  npm run dev

#  Move into the backend project folder
  cd backend 


# install package
  npm install express
  npm install jwt
  npm install react-router-dom
  npm install react-router
  npm install bcyptjs

  
# start the server
 npm index.js

## 📌 Features

### For Job Seekers:
- User registration and login
- Search and filter jobs by category, location, type
- View job details
- Apply to jobs
- Manage applications in dashboard

### For Employers:
- Employer registration and login
- Post, edit, delete job listings
- View applicants
- Manage company profile

### Admin:
- Dashboard to manage users, jobs, and reports

---

## 🛠️ Tech Stack

**Frontend:**
- React.js 
- Redux / Context API (for state management)
- Axios (for API requests)
- Tailwind CSS 

**Backend:**
- Node.js + Express.js
- MongoDB 
- JWT Authentication
- Multer (for file uploads)
- Cloudinary / AWS S3 (for image storage)

**Other Tools:**
- Git & GitHub
- Postman (API testing)
